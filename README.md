# 矩阵初等变换交互游戏

用 Python 把线性代数里的「初等矩阵 / 左乘行变换、右乘列变换」做成一个可以反复练习的小游戏。

程序随机生成一个 3×3 整数矩阵和一次初等变换，玩家需要回答两件事：

1. 这次变换对应的**初等矩阵**是什么；
2. 这一步是**左乘**还是**右乘**。

答对继续下一题，答错会给出正确答案。

> 小提示：程序会把单位矩阵一起打印出来，可以直接复制它、把其中一个 `1` 改成要考的倍数，就不用手敲整个 3×3 矩阵了。

## 核心思路

- **字典调度**：把六种初等变换函数按编号存进字典，按随机编号统一调用，避免冗长的 `if/elif` 分支。
- **单位矩阵同步变换**：初等矩阵就是单位矩阵 E 经过同样一次变换得到的。让 E 和题目矩阵走同一个变换函数，就能一次拿到「标准答案」与「变换结果」，不用手工推导公式。
- **用矩阵乘法判方向**：通过比较 `E × M` 与 `M × E` 哪一个等于变换结果，判断这一步是左乘还是右乘；当两种结果恰好相同时（例如对角矩阵），再按变换类型兜底。

## 运行

需要 Python 3.8 以上，无第三方依赖：

```bash
python 1.py
```

输入格式：用嵌套列表，例如 `[[1,0,0],[0,1,0],[0,0,2]]`；左右乘输入 `left` 或 `right`。
